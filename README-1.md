# Очередь

PvP-игра для Telegram на aiogram 3. Два игрока, одна очередь позиций, часть позиций копии.
Матч идёт до двух выигранных смен, по оценке из симуляции это 6–9 минут.

## Механика

**Очередь.** В каждом заряде 4–8 позиций. У каждой есть лицо (символ), лица видны обоим, правда скрыта.

- Одиночное лицо всегда оригинал.
- Два одинаковых лица: одна из двух позиций копия. В смене 3 пара может состоять из близнецов (◐ и ◑).
- Вскрыли одну позицию пары, и вторая известна наверняка.

**Ход.** Любое число предметов, затем одно из двух:

- Принять: вскрыть следующую позицию на себя. Копия: −1 жизнь, ход уходит. Оригинал: ходишь снова.
- Отдать: вскрыть на соперника. Копия: −1 ему. Оригинал: ничего. Ход уходит в любом случае.

Когда очередь кончилась, выдаётся новый заряд.

**Смены.**

| Смена | Жизни | Предметов на заряд |
|-------|-------|--------------------|
| 1     | 2     | 0                  |
| 2     | 3     | 2                  |
| 3     | 4     | 3                  |

Побеждает выигравший две смены. Проигравший смену ходит первым в следующей. Слотов под предметы 5, в конце смены они сгорают.

**Таймер.** 40 секунд на ход. Время вышло: случайный ход без предметов. Два раза подряд: смена проиграна.

**Предметы.**

| Предмет      | Действие |
|--------------|----------|
| Сверка       | Выбираешь пару лиц и узнаёшь, какая из двух позиций копия. Ответ только тебе, сопернику видно, какую пару ты сверял. |
| Перестановка | Две соседние позиции меняются местами. Видно обоим. |
| Задержка     | Соперник пропускает следующий ход. |
| Перевязка    | +1 жизнь, не выше максимума смены. |
| Копирование  | Копия любого предмета соперника, у него предмет остаётся. |
| Помеха       | На один ход соперника лица скрыты, Сверка и Перестановка ему недоступны. |
| Невозможное  | Отменяет следующий удар по тебе. Редкий. |

В смене 3 Сверка может ошибаться. Ошибку можно поймать, сверив пару, одну позицию которой уже вскрыли.

## Запуск

```bash
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
export BOT_TOKEN=123456:ABC...     # Windows: set BOT_TOKEN=123456:ABC...
python bot.py
```

Токен выдаёт @BotFather. Переменные окружения:

| Переменная     | По умолчанию | Назначение |
|----------------|--------------|------------|
| `BOT_TOKEN`    | обязательна  | токен бота |
| `TURN_SECONDS` | `40`         | время на ход |
| `DB_PATH`      | `ratings.db` | файл SQLite с рейтингом |

## Команды

| Команда      | Что делает |
|--------------|------------|
| `/queue`     | рейтинговая партия со случайным соперником (только в личке) |
| `/duel`      | в личке: ссылка-приглашение. В группе: стол с кнопкой «Сесть за стол». Без рейтинга |
| `/surrender` | сдать матч |
| `/rules`     | правила |
| `/items`     | справка по предметам |
| `/me`, `/top`| рейтинг |

Обоим игрокам нужно хотя бы раз открыть бота в личке и нажать `/start`: партия идёт в личных сообщениях.

## Структура

- `engine.py` правила игры, без Telegram.
- `bot.py` хэндлеры aiogram, отрисовка стола, таймеры, рейтинг (Elo, SQLite).
- `test_engine.py` проверка инвариантов на тысячах случайных партий и оценка баланса.

## Тесты

```bash
python test_engine.py
```

aiogram для тестов не нужен. По симуляции: в зеркале первый ход выигрывает матч в 53,4% случаев, разумная стратегия обыгрывает случайную в 97% матчей.

## Ограничения

- Идущие партии хранятся в памяти и пропадают при перезапуске бота.
- Нет стола на 3–4 игрока, быстрой партии и разблокируемых модификаторов.
- Бот проверен на заглушке aiogram, на живом Telegram прогона ещё не было.
